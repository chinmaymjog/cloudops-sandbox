# Security Policy

This is a local lab on Docker Compose, but its stacks expose web UIs and a
database, so insecure defaults matter if anyone runs it on a reachable host.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
<https://github.com/chinmaymjog/cloudops-sandbox/security/advisories/new>

Never include real passwords, tokens or host addresses in issues or pull
requests; use redacted values.

You can expect an initial response within a few days.

## Supported versions

Only the latest `main` receives security fixes.
